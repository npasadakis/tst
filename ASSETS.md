## Image Guidelines

### General Recommendations
- **Format:** JPG for photos, PNG for graphics with transparency, SVG for logos
- **Quality:** High resolution (at least 1200px on the longest side)
- **File size:** Optimize for web (aim for under 500KB per image when possible)
- **Aspect ratios:**
  - Hero images: 16:9 or wider
  - Gallery images: 4:3 or 16:9
  - Trip cards: 4:3
  - Header images: 16:9 or 21:9

### Photography Tips
- Use high-quality, professional photos
- Ensure good lighting (golden hour is ideal)
- Show happy customers (with permission)
- Capture the boat, the sea, Dia Island, and activities
- Include variety: close-ups, wide shots, action shots, and atmospheric images
- Show the Greek flag or local elements to emphasize location

### Video Guidelines
- **Format:** MP4 (H.264 codec)
- **Duration:** 30-60 seconds (loop-friendly)
- **Resolution:** 1920x1080 minimum, 4K preferred
- **Frame rate:** 30fps or 60fps
- **Content:** Smooth footage, avoid jerky camera movements
- **Audio:** Not required (will be muted)
- **File size:** Compress to under 10MB if possible

## How to Add Assets

1. Replace placeholder files with actual images/videos
2. Keep the same filename to maintain website functionality
3. Ensure images are optimized for web
4. Test the website after adding new assets
5. Consider using tools like TinyPNG or ImageOptim for compression
