# Website Assets

This directory contains all images and videos for the sailing business website.

## Required Assets

### Logo
Place your logo in `images/logo/`:
- **logo.png** - Main logo (recommended: 200x200px, transparent background)
- **logo-white.png** - White version for dark backgrounds (optional)

### Hero Video
Place your hero video in `videos/`:
- **sailing-hero.mp4** - Main hero video (recommended: 1920x1080, H.264 codec, ~30 seconds)
- **sailing-hero-mobile.mp4** - Mobile version (optional, 720x1280)

### Trip Images
Place trip-specific images in `images/trips/`:
- **private-sailing-1.jpg** to **private-sailing-6.jpg** - Private sailing charter images
- **full-day-1.jpg** to **full-day-6.jpg** - Full day trip images
- **half-day-1.jpg** to **half-day-6.jpg** - Half day trip images

### Gallery Images
Place general gallery images in `images/gallery/`:
- **gallery-1.jpg** to **gallery-12.jpg** - General sailing and scenery photos
- Recommended resolution: 1200x900px (4:3 ratio)

### Featured Images
Place large featured images in `images/`:
- **hero-bg.jpg** - Hero background image fallback (1920x1080)
- **dia-island.jpg** - Dia Island feature image
- **sailing-sunset.jpg** - Sunset sailing image
- **heraklion-port.jpg** - Heraklion port image

## Image Specifications

### Recommended Formats
- **Photos**: JPG (quality 85-90%)
- **Graphics/Logo**: PNG with transparency
- **Large images**: WebP format for better compression (optional)

### Recommended Sizes
- Hero images: 1920x1080px
- Gallery images: 1200x900px
- Trip images: 800x600px
- Thumbnails: 400x300px

### Optimization
- Compress all images before uploading
- Use tools like TinyPNG, ImageOptim, or Squoosh
- Target file sizes: <200KB for gallery images, <500KB for hero images

## Video Specifications

### Hero Video
- **Resolution**: 1920x1080 (Full HD)
- **Duration**: 20-40 seconds (short loop)
- **Format**: MP4 (H.264 codec)
- **File size**: <10MB (compressed for web)
- **Frame rate**: 30fps
- **Content**: Sailing footage, sea views, boat shots, Dia Island

### Optimization Tips
- Use HandBrake or FFmpeg for compression
- Remove audio track if not needed
- Use web-optimized settings
- Consider creating a poster frame image
